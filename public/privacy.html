隱私權政策

應用程式：freelance　·　生效日：2026 年 9 月 3 日

這是什麼

freelance 是一個僅供開發者本人使用的命令列工具，執行於開發者自己的電腦上，用來存取開發者本人的 Google 帳戶資料。本工具不對外提供、不開放註冊，亦無其他使用者。

存取哪些資料

經由 Google OAuth 授權後，本工具可存取授權帳戶中的下列 Google 服務資料：

  • Google Drive（檔案與資料夾）
  • Google Forms、Sheets、Docs、Slides
  • Gmail、Google Calendar、Google Meet

實際存取範圍以每次授權時同意畫面所列的權限為準。

如何使用

資料僅在開發者本人的電腦上，於執行指令的當下讀取或寫入，用途為建立與管理開發者自己的文件、表單與行程。

儲存與傳輸

  • OAuth 存取權杖與更新權杖儲存於開發者電腦的 macOS Keychain。
  • 本工具沒有伺服器、沒有資料庫，不會將任何資料上傳至第三方。
  • 所有網路連線僅發生於本機與 Google API 之間。

分享與販售

不分享、不販售、不轉讓任何資料給任何第三方。不會將資料用於廣告、分析或訓練模型。

保留與刪除

本工具不另行保留資料副本。要撤銷存取權，可於 Google 帳戶權限頁面 移除本應用程式，或在本機執行 gws auth logout 清除已儲存的憑證。

Google API 服務使用者資料政策

本應用程式使用 Google API 所取得之資訊，其使用與轉移皆遵循 Google API Services User Data Policy，包含其中的「有限使用」（Limited Use）規定。

Privacy Policy

Application: freelance　·　Effective: September 3, 2026

What this is

freelance is a personal command-line tool used solely by its developer, running on the developer's own computer to access the developer's own Google account data. It is not offered to the public, has no sign-up, and has no other users.

Data accessed

After Google OAuth authorization, the tool can access data in the authorizing account across Google Drive, Forms, Sheets, Docs, Slides, Gmail, Calendar, and Meet. The effective scope is whatever is listed on the consent screen at the time of authorization.

How it is used

Data is read or written only on the developer's own machine, at the moment a command is run, to create and manage the developer's own documents, forms, and events.

Storage and transmission

  • OAuth access and refresh tokens are stored in the macOS Keychain on the developer's computer.
  • There is no server and no database. No data is uploaded to any third party.
  • All network traffic is between the local machine and Google's APIs.

Sharing and sale

No data is shared, sold, or transferred to any third party. No data is used for advertising, analytics, or model training.

Retention and deletion

No separate copies are retained. Access can be revoked at Google Account permissions, or locally with gws auth logout.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
